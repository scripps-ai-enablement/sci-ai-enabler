# Curator state

## Recently surfaced

- **Fit a survival model to censored clinical outcomes** (added 2026-06-06) — rung-2 [scikit-survival skill](../catalog/tools/scikit-survival.html) recipe taking a covariate table + `(time, event)` outcome through structured-`Surv` encoding → Kaplan-Meier + log-rank → Cox PH with a proportional-hazards check → Random Survival Forest → 5-fold cross-validated Harrell's c-index → risk-group stratification. First Translational Medicine focus-day recipe of this run; cookbook's first time-to-event / prognosis recipe. `Proposed` — no documented LLM-driven `sksurv` end-to-end; closest grounding is the library reference [Pölsterl, *JMLR* 21(212):1–6 (2020)](https://jmlr.org/papers/v21/20-729.html) plus recent RSF-vs-nomogram prognosis studies [Zhang et al., *Transl. Cancer Res.* (2026)](https://doi.org/10.21037/tcr-2025-aw-2462) and [Liu et al., *Medicine* (2026)](https://doi.org/10.1097/MD.0000000000048757).
- **Scan adverse-event reports for a drug-safety signal** (added 2026-06-06) — rung-2 [OpenFDA MCP](../catalog/tools/openfda.html) recipe taking a drug name through generic-name resolution → FAERS top-reaction ranking → structured label/warning pull → label-vs-FAERS cross-check → "reports, not rates" framing. Second Translational Medicine focus-day recipe; promoted from `Deferred — next-run priority`; cookbook's first pharmacovigilance recipe. `Proposed` — no documented attempt of this exact MCP assembly; openFDA/FAERS is the canonical public pharmacovigilance source and the server wraps it faithfully.
- **Organize a raw DICOM dataset into a BIDS layout** (added 2026-06-05) — rung-2 [BIDS Claude Skill](../catalog/tools/bids.html) recipe taking a directory of vendor DICOMs through series-level inventory → HeuDiConv heuristic (or dcm2bids config) drafting → single-subject `--dry-run` audit → cohort conversion with `dcm2niix` → top-level `dataset_description.json` / `participants.tsv` / sidecar authoring → `bids-validator` triage → PyBIDS post-conversion query, with explicit `IntendedFor` cross-link logic for fieldmaps. First Neuroscience focus-day recipe of this run; cookbook's first imaging-side data-organization recipe (counterpart to the existing NWB/DANDI electrophysiology discovery recipe). Promoted from the `Deferred — next-run priority` list. `Proposed` evidence — no documented end-to-end LLM-driven DICOM→BIDS workflow in last-24-months literature; closest component-level grounding is [Gorgolewski et al., *Sci. Data* 3:160044 (2016)](https://doi.org/10.1038/sdata.2016.44), [Poldrack et al., *Imaging Neuroscience* 2:1–19 (2024)](https://doi.org/10.1162/imag_a_00103) (BIDS spec evolution), [Yarkoni et al., *JOSS* 4(40):1294 (2019)](https://doi.org/10.21105/joss.01294) (PyBIDS), [Zwiers et al., *Front. Neuroinform.* 15:770608 (2022)](https://doi.org/10.3389/fninf.2021.770608) (BIDScoin), and [Wulms et al., *Sci. Data* 10:673 (2023)](https://doi.org/10.1038/s41597-023-02583-4) (BIDSconvertR).
- **Run functional enrichment on a gene list** (added 2026-06-04) — rung-2 [gget skill](../catalog/tools/gget.html) recipe taking a gene-symbol list through `gget enrichr` against GO BP, KEGG, Reactome, MSigDB Hallmark, and DisGeNET → per-library CSV → grounded natural-language summary with an explicit verification pass against the saved tables and a random-gene negative-control step. First Molecular and Cellular Biology focus-day recipe of this run; cookbook's first dedicated functional-enrichment / pathway-interpretation recipe and the natural downstream step after the bulk RNA-seq DE recipe. `Reported` evidence anchored in [Wang et al., *GeneAgent*, *Nature Methods* 22:1677, 2025](https://doi.org/10.1038/s41592-025-02748-6) — self-verification against Enrichr / curated DBs lifts ROUGE-L on MSigDB from 0.239±0.038 (GPT-4) to 0.310±0.047 (GeneAgent) across 1,106 gene sets, with 84% of 15,848 claims database-supported and 92% of self-verification decisions correct on a 132-claim expert sample; complementary anchors [Hu et al., *Nat. Methods* 21:2353, 2024](https://doi.org/10.1038/s41592-024-02525-x) and [Joshi et al., *llm2geneset* (bioRxiv 2024-11-12)](https://doi.org/10.1101/2024.11.11.621189).
- **Dock a ligand library into a target structure with DiffDock** (added 2026-06-03) — rung-2 [DiffDock skill](../catalog/tools/diffdock.html) recipe taking a PDB or AlphaFold target plus a SMILES CSV through batch-CSV prep → diffusion sampling (20–40 samples/complex) → confidence-thresholded filtering (> 0 trustworthy, −1.5 to 0 inspect, < −1.5 drop) → top-K SDF export, with explicit handoffs to MedChem / DeepChem / MD-rescoring downstream. First Integrative Structural and Computational Biology focus-day recipe of this run; cookbook's first dedicated docking recipe and natural downstream of the existing AlphaFold-triage recipe. `Proposed` evidence — no documented end-to-end LLM-orchestrated DiffDock virtual screen. Closest component-level evidence: [Corso et al., DiffDock-L (ICLR 2024, arXiv:2402.18396)](https://arxiv.org/abs/2402.18396) — 38%→80% RMSD<2Å when filtering to top one-third by confidence on PDBBind; [Buttenschoen et al., PoseBusters (*Chem. Sci.* 15:3130, 2024)](https://doi.org/10.1039/D3SC04185A); [Karelina et al., AlphaFold-target docking (*JCIM* 63:6219, 2023)](https://doi.org/10.1021/acs.jcim.3c00601) at ~21% RMSD<2Å on AF2 models — motivates the upstream-triage gate in step 2.
