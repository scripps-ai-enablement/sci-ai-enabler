# Curator state

## Recently surfaced

- **Superpose two protein structures and quantify where they differ** (added 2026-07-04) — rung-2 [PyMOL skill](../catalog/tools/pymol.html) recipe: two coordinate files (AlphaFold model vs experimental PDB, or apo vs holo) → `cealign`/`super` superposition → global RMSD + per-residue Cα-deviation `perres.csv` + deviation-coloured overlay PNG + `.pse` + committed `.claude/commands/superpose.md` + `uv`-pinned env + `provenance.json` (PyMOL version, method + cutoff, both input sha256s, chain selectors, aligned-atom count, RMSD, fetch date/accession, model id). Integrative Structural and Computational Biology focus-day recipe; cookbook's first use of the catalogued PyMOL skill, cross-linked to the [Foldseek function recipe](items/infer-protein-function-from-structure.html) (database-search counterpart) and the [AlphaFold triage recipe](items/triage-alphafold-model-for-docking.html) (confidence-side counterpart). `Proposed` — no LLM-driven superposition workflow is documented; grounded on peer-reviewed PyMOL `cealign` ([Shindyalov & Bourne, *Protein Eng.* 1998](https://doi.org/10.1093/protein/11.9.739)) and AlphaFold model-vs-experiment RMSD ([Jumper et al., *Nature* 2021](https://doi.org/10.1038/s41586-021-03819-2)). `Fully open`, `Laptop`.
- **Identify a bacterial isolate from its 16S rRNA sequence** (added 2026-07-04) — rung-2 [BLAST (Bio-MCP)](../catalog/tools/blast.html) recipe: a colony-PCR Sanger 16S read (or assembled 16S contig) → `blastn` against a pinned curated 16S database (NCBI `16S_ribosomal_RNA`) → coverage-filtered, identity-ranked `hits.csv` with a threshold-based `assignment` column (98.7% species / 94.5% genus) + committed `identify_16s.py` + pinned env + `provenance.json` (BLAST+ version, 16S DB release + sha256, query sha256, cutoffs, run date, model id). Immunology and Microbiology focus-day recipe; single-isolate identification counterpart to the community-level [16S diversity recipe](items/compute-16s-microbiome-diversity.html), cross-linked to the [resistome screen](items/screen-genome-for-resistance-and-virulence-genes.html) (same tool), the [annotation recipe](items/annotate-a-bacterial-genome.html) (consumes the genus hint), and the [phylogenetic-tree recipe](items/build-phylogenetic-tree-from-sequences.html). `Reported` — 98.7%/94.5% identity thresholds are the community standard ([Kim et al., *IJSEM* 2014](https://doi.org/10.1099/ijs.0.059774-0); [Yarza et al., *Nat. Rev. Microbiol.* 2014](https://doi.org/10.1038/nrmicro3330)); the BLAST-MCP assembly is not separately benchmarked. `Fully open`, `Laptop`.
- **Screen a bacterial genome for resistance and virulence genes** (added 2026-07-04) — rung-2 [BLAST (Bio-MCP)](../catalog/tools/blast.html) recipe: an annotated genome's protein FASTA → `makeblastdb` + `blastp` against pinned CARD and VFDB references → identity/coverage-filtered best-hit-per-database → `resistance_hits.csv` + `virulence_hits.csv` + committed `screen_resistome.py` + pinned env + `provenance.json` (BLAST+ version, CARD release, VFDB download date, FASTA sha256s, cutoffs, input sha256). Immunology and Microbiology focus-day recipe; picks up the AMR/virulence step the [bacterial-genome-annotation recipe](items/annotate-a-bacterial-genome.html) explicitly punts to the CLI, cross-linked to it and the [pan-genome recipe](items/compute-bacterial-pangenome-from-assemblies.html). `Reported` — `blast+` AMR/virulence detection validated at >95% sensitivity/specificity on a 131-isolate reference collection ([Bogaerts et al., *Microb. Genom.* 2021](https://doi.org/10.1099/mgen.0.000531)); the BLAST-MCP assembly is not separately benchmarked. `Fully open`, `Laptop`.
- **Rank a compound library against a target by predicted binding affinity** (added 2026-06-28) — rung-2 [Boltz plugin](../catalog/tools/boltz.html) recipe driving the hosted `boltz-small-molecule-screen` skill: a target sequence/PDB + a SMILES library → MedChem/Datamol pre-filter → structure-and-affinity screen on the hosted Boltz API (no local GPU) → `screen_ranked.csv` (affinity, binder probability, structure confidence) + committed `rank_screen.py` + `.claude/commands/boltz-affinity-screen.md` + pinned env + `provenance.json` (Boltz model id, job IDs, submission date, input sha256, target accession), ranking by the classifier score rather than fine affinity gaps. Drug Repurposing and Discovery focus-day recipe; cookbook's first GPU-free structure-based affinity-screening recipe, cross-linked to the [DiffDock recipe](items/dock-ligand-library-with-diffdock.html) (GPU pose-level counterpart) and the [virtual-screening hit filter](items/filter-virtual-screening-hits.html) (upstream). `Reported` — Boltz-2 approaches FEP accuracy ([Passaro et al., bioRxiv 2025](https://www.biorxiv.org/content/10.1101/2025.06.14.659707v1)) but is a good binder classifier and weak quantitative ranker per an independent eval ([Wan et al., arXiv:2603.05532, 2026](https://arxiv.org/abs/2603.05532)); the Claude-plugin assembly is not separately benchmarked. `Subscription required`, `Laptop`.
- **Register longitudinal medical scans to a common frame** (added 2026-06-28) — rung-2 [SimpleITK skill](../catalog/tools/simpleitk-image-registration.html) recipe: baseline + follow-up CT/MRI → rigid (Euler3D, Mattes MI) → deformable (B-spline) registration → `warped.nii.gz` + `transform.tfm` + propagated label mask + committed `register_scans.py` + pinned env + `provenance.json`, with a checkerboard QC step. Translational Medicine focus-day recipe; cookbook's first image-registration recipe. `Reported`, `Fully open`, `Workstation with GPU`.

## Missing components

- **ANI / MLST caller (fastANI / pyani / mlst)** — the new [identify-bacterial-isolate-from-16s-sequence recipe](items/identify-bacterial-isolate-from-16s-sequence.html) gives a fast 16S-based genus/species call, but 16S alone frequently ties multiple close species. Definitive species delineation needs whole-genome average nucleotide identity ([fastANI](https://github.com/ParBLiSS/FastANI), [pyani](https://github.com/widdowquinn/pyani)) or multi-locus sequence typing ([tseemann/mlst](https://github.com/tseemann/mlst)). None is Claude-installable (skill/MCP/plugin) today. Would unlock a confirmatory species-delineation recipe downstream of the 16S ID. Surfaced 2026-07-04.
- **Dedicated resistome caller (RGI / AMRFinderPlus)** — the new [screen-genome-for-resistance-and-virulence-genes recipe](items/screen-genome-for-resistance-and-virulence-genes.html) uses the catalogued [BLAST MCP](../catalog/tools/blast.html) for straight homology detection against CARD/VFDB, but RGI ([arpcard/rgi](https://github.com/arpcard/rgi)) and NCBI AMRFinderPlus add SNP/protein-variant models that catch point-mutation resistance (e.g. `gyrA` fluoroquinolone mutations) a homology search misses. Neither is Claude-installable (skill/MCP/plugin) today. Would upgrade the AMR recipe from homology-only to variant-aware. Surfaced 2026-07-04.
- **Biobank-scale mixed-model GWAS wrapper (regenie / SAIGE / BOLT-LMM)** — the catalogued [PLINK2 skill](../catalog/tools/plink2-gwas-analysis.html) covers array/small-cohort fixed-effect GWAS (now the [case-control GWAS recipe](items/run-gwas-on-case-control-genotypes.html)), but cohorts of 100k+ samples with relatedness/structure need a linear mixed model to control inflation. No regenie/SAIGE/BOLT-LMM component is Claude-installable today. Would unlock a biobank-scale sibling recipe. Surfaced 2026-06-14.
- **pySCENIC wrapper (cisTarget + AUCell)** — no Claude-installable component for the steps downstream of GRNBoost2 (motif filtering against cisTarget databases, per-cell regulon AUCell scoring). Would unlock a full SCENIC-pipeline recipe on top of the new GRN-inference recipe. Surfaced 2026-05-28.
- **ADMET-AI / AdmetLab 3.0 / Deep-PK wrapper** — none of the leading ML-based ADMET predictors ([Swanson et al., *Bioinformatics* 2024](https://doi.org/10.1093/bioinformatics/btae416); [Fu et al., *NAR* 2024](https://doi.org/10.1093/nar/gkae236)) has a Claude-installable wrapper (skill, MCP server, or plugin) in [`catalog/tools/`](../catalog/) today. Their inclusion would upgrade the *Estimate PK properties* recipe from descriptor-and-analog-anchored estimation to a defensible ML-prediction layer for endpoints (CYP isoform IC50, hERG IC50, microsomal clearance) that pure descriptors miss. Surfaced 2026-05-27.
- **MARRVEL-MCP** ([bioRxiv 2025-11-26](https://www.biorxiv.org/content/10.1101/2025.11.26.690887v1), [`hyunhwan-bcm/MARRVEL_MCP`](https://github.com/hyunhwan-bcm/MARRVEL_MCP/)) — rare-disease variant-interpretation MCP server with 39 tools and a published 95%-accuracy benchmark on 45 expert-curated tasks. Would strengthen the *Interpret a clinical variant* recipe from `Proposed` to `Reported` and open a Mendelian-disease-specific recipe. Surfaced 2026-05-23.
