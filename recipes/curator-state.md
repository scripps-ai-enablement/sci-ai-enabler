- **Annotate tumor somatic variants with clinical actionability evidence** (added 2026-07-26) — rung-2 [CIViC connector](../catalog/tools/civic.html) recipe filling the precision-oncology actionability gap: tumor somatic variant list → per-variant CIViC clinical-evidence match → committed `annotate_actionability.py` + pinned env + `actionability.csv` (evidence type, disease, therapy/outcome, A–E level, citation, evidence id) + suggested AMP/ASCO/CAP tier + `provenance.json` (CIViC release date, connector id, input sha256).
