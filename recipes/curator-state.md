# Curator state

## Recently surfaced

- **Extract event-related potentials from EEG epochs** (added 2026-07-12) — rung-2 [MNE-Python (EEG) skill](../catalog/tools/mne-eeg-tool.html) recipe: raw continuous EEG + events → standard_1020 montage / average reference → band-pass 0.1–40 Hz + 60 Hz notch → picard ICA with logged EOG-component removal → epoch (−0.2 to 0.8 s) + baseline + peak-to-peak rejection → per-condition evoked averaging → committed `preprocess_erp.py` + pinned env + `*_ave.fif`/`erp_counts.csv` + butterfly/difference-wave figures + `provenance.json` (MNE version, montage, filter cutoffs, ICA method + dropped-component indices + seed, rejection threshold, per-condition kept/rejected counts, input sha256, run date, model id). Neuroscience focus-day recipe; cookbook's first EEG-analysis recipe, sibling to the single-signal [HRV recipe](items/compute-hrv-from-ecg-recording.html) and runnable on public EEG found via the [DANDI recipe](items/discover-nwb-recordings-on-dandi.html). `Reported` — MNE-Python is the field-standard M/EEG toolbox ([Gramfort et al., *Front. Neurosci.* 2013](https://doi.org/10.3389/fnins.2013.00267)); the filter→ICA→epoch→average ERP workflow is reused across recent reproducible-pipeline packages built on it ([EEG-Pype, *PLoS Comput. Biol.* 2026](https://doi.org/10.1371/journal.pcbi.1014043); [osl-ephys, *Front. Neurosci.* 2025](https://doi.org/10.3389/fnins.2025.1522675)); the agent-driven assembly is not separately benchmarked. `Fully open`, `Laptop`.
- **Quantify bulk RNA-seq FASTQ into a gene-level counts matrix** (added 2026-07-11) — rung-3 toolbelt: [fastp skill](../catalog/tools/fastp-fastq-preprocessing.html) trim → [Salmon skill](../catalog/tools/salmon-rna-quantification.html) decoy-aware quasi-mapping (`--gcBias --seqBias --validateMappings`) → tximport gene-level aggregation via `tx2gene` → committed `quantify_rnaseq.py` + pinned `requirements.txt` + per-sample fastp JSON QC + `counts.csv`/`coldata.csv` + `provenance.json` (transcriptome source/release, index flags, FASTQ sha256, tool versions, run date, model id). Molecular and Cellular Biology focus-day recipe; fills the FASTQ→counts gap explicitly assumed-away by the [bulk RNA-seq DE recipe](items/run-bulk-rnaseq-differential-expression.html), which is now cross-linked as its downstream companion; alignment-based alternative noted via [STAR](../catalog/tools/star-rna-seq-aligner.html)+[featureCounts](../catalog/tools/featurecounts-rna-counting.html). `Proposed` — grounded on Salmon's bias-aware/decoy-aware benchmarks ([Patro et al., *Nat. Methods* 2017](https://doi.org/10.1038/nmeth.4197); [Srivastava et al., *Genome Biol.* 2020](https://doi.org/10.1186/s13059-020-02151-8)) and tximport gene-level aggregation ([Soneson et al., *F1000Res* 2015](https://doi.org/10.12688/f1000research.7563.2)); the agent-orchestrated chain is not separately benchmarked. `Fully open`, `Laptop`.
- **Predict a protein–protein complex to map the binding interface** (added 2026-07-11) — rung-2 [Boltz plugin](../catalog/tools/boltz.html) recipe: two partner FASTA sequences → `boltz-structure-and-binding` multi-chain co-folding with wide sampling → local 5 Å inter-chain contact recomputation → committed `.claude/commands/predict-ppi-interface.md` + `interface_from_boltz.py` + pinned env + `interface.csv` (per-model + consensus interface residues) + `provenance.json` (plugin version, boltz-api job ids/date, model id, input sha256). Integrative Structural and Computational Biology focus-day recipe; the general non-antibody PPI counterpart to the [antibody–antigen complex recipe](items/predict-antibody-antigen-complex.html), sharing its sample-wide/rank-by-consensus discipline; upstream single-chain check is the [AlphaFold-triage recipe](items/triage-alphafold-model-for-docking.html). Closes the long-deferred "AlphaFold-Multimer complex interface" candidate now that Boltz is catalogued. `Reported` — Boltz-2 matches AF3 on held-out PDB 2024–2025 complexes ([Passaro et al., *bioRxiv* 2025](https://www.biorxiv.org/content/10.1101/2025.06.14.659707v1)); AF-Multimer/AF3 are field-standard multimer baselines ([Hou et al., *Nat. Commun.* 2025](https://pubmed.ncbi.nlm.nih.gov/41261173/)); the Claude-plugin assembly is not separately benchmarked. `Subscription required` (hosted Boltz API; data-residency caveat for proprietary sequences), `Laptop`.
- **Scan a protein for candidate CD8 T-cell epitopes** (added 2026-07-11) — rung-2 [MHC Binding Prediction skill](../catalog/tools/mhc-binding-prediction.html) recipe: antigen FASTA + HLA class I alleles → tile to 8–11-mers → MHCflurry (+optional NetMHCpan-4.1/MixMHCpred) presentation + `%Rank` scoring → committed `scan_epitopes.py` + pinned env + `epitopes.csv` (peptide, allele, affinity_nM, presentation_score, percent_rank, strong/weak flag) + `provenance.json` (predictor versions/model release, allele list, length set, input sha256, run date, model id). Immunology and Microbiology focus-day recipe; cookbook's first MHC-I epitope recipe, sibling to the broader [epitope-prediction skill](../catalog/tools/epitope-prediction.html) (B-cell/class II) and the structural [antibody–antigen complex recipe](items/predict-antibody-antigen-complex.html). `Validated` — NetMHCpan-4.0/MHCflurry captured >half of the major T-cell epitopes in the top 277 of 767,788 candidates in a proteome-wide benchmark ([Paul et al., *PLoS Comput. Biol.* 2020](https://pubmed.ncbi.nlm.nih.gov/32453790/)); eluted-ligand+affinity training improves neoantigen ID ([Jurtz et al., *J. Immunol.* 2017](https://pubmed.ncbi.nlm.nih.gov/28978689/)); SOTA reconfirmed 2026 ([Mecklenbräuker et al., *Mol. Cell. Proteomics*](https://pubmed.ncbi.nlm.nih.gov/41903651/)); the agent-driven assembly is not separately benchmarked. `Fully open` (MHCflurry local; NetMHCpan/MixMHCpred optional academic downloads), `Laptop`.
- **Reconstruct B-cell clonal lineages from AIRR-seq** (added 2026-07-11) — rung-2 [Immcantation BCR Analysis skill](../catalog/tools/immcantation-analysis.html) recipe: AIRR rearrangement table → shazam data-derived clonal threshold (findThreshold, no hardcoded cutoff) → scoper clonal families → region-aware SHM + BASELINe selection → dowser germline-rooted, codon-aware lineage trees for the N largest clones → committed `bcr_lineages.R` + pinned Immcantation Docker/renv + `clones.tsv`/tree outputs + `provenance.json` (package versions, IMGT germline release, derived threshold, input sha256, run date, model id). Immunology and Microbiology focus-day recipe; cookbook's first BCR clonal-analysis recipe, feeding the [antibody–antigen complex recipe](items/predict-antibody-antigen-complex.html) and [glycosylation-scan recipe](items/scan-antibody-glycosylation-sites.html) for expanded-clone follow-up. `Reported` — Immcantation is the documented AIRR-seq clonal-analysis standard with an active supporting methods literature ([Abdollahi et al., *BMC Bioinformatics* 2023](https://pubmed.ncbi.nlm.nih.gov/36849917/); [Zhang et al., *Front. Immunol.* 2022](https://pubmed.ncbi.nlm.nih.gov/36618367/); [Jeusset et al., *NAR Genom. Bioinform.* 2023](https://pubmed.ncbi.nlm.nih.gov/37388820/)); the agent-orchestrated assembly is not separately benchmarked. `Fully open`, `Laptop`.

## Missing components

- **Local pH-aware protonation-state enumerator (Dimorphite-DL / OpenBabel `-p` / ChemAxon cxcalc)** — the new [prepare-protonation-states-for-docking recipe](items/prepare-protonation-states-for-docking.html) uses the [Rowan skill](../catalog/tools/rowan.html) `submit_macropka_workflow`, which runs cloud-side (SMILES leave the machine — a data-residency blocker for confidential structures). A Claude-installable *local* pH-aware protonator ([Dimorphite-DL](https://durrantlab.pitt.edu/dimorphite-dl/), OpenBabel `-p`) would enable an offline sibling recipe and remove the cloud caveat. Datamol/RDKit standardize charges/tautomers but are pH-blind, so no catalogued local component covers this today. Surfaced 2026-07-11.
- **ANI / MLST caller (fastANI / pyani / mlst)** — the new [identify-bacterial-isolate-from-16s-sequence recipe](items/identify-bacterial-isolate-from-16s-sequence.html) gives a fast 16S-based genus/species call, but 16S alone frequently ties multiple close species. Definitive species delineation needs whole-genome average nucleotide identity ([fastANI](https://github.com/ParBLiSS/FastANI), [pyani](https://github.com/widdowquinn/pyani)) or multi-locus sequence typing ([tseemann/mlst](https://github.com/tseemann/mlst)). None is Claude-installable (skill/MCP/plugin) today. Would unlock a confirmatory species-delineation recipe downstream of the 16S ID. Surfaced 2026-07-04.
- **Dedicated resistome caller (RGI / AMRFinderPlus)** — the new [screen-genome-for-resistance-and-virulence-genes recipe](items/screen-genome-for-resistance-and-virulence-genes.html) uses the catalogued [BLAST MCP](../catalog/tools/blast.html) for straight homology detection against CARD/VFDB, but RGI ([arpcard/rgi](https://github.com/arpcard/rgi)) and NCBI AMRFinderPlus add SNP/protein-variant models that catch point-mutation resistance (e.g. `gyrA` fluoroquinolone mutations) a homology search misses. Neither is Claude-installable (skill/MCP/plugin) today. Would upgrade the AMR recipe from homology-only to variant-aware. Surfaced 2026-07-04.
- **Biobank-scale mixed-model GWAS wrapper (regenie / SAIGE / BOLT-LMM)** — the catalogued [PLINK2 skill](../catalog/tools/plink2-gwas-analysis.html) covers array/small-cohort fixed-effect GWAS (now the [case-control GWAS recipe](items/run-gwas-on-case-control-genotypes.html)), but cohorts of 100k+ samples with relatedness/structure need a linear mixed model to control inflation. No regenie/SAIGE/BOLT-LMM component is Claude-installable today. Would unlock a biobank-scale sibling recipe. Surfaced 2026-06-14.
- **pySCENIC wrapper (cisTarget + AUCell)** — no Claude-installable component for the steps downstream of GRNBoost2 (motif filtering against cisTarget databases, per-cell regulon AUCell scoring). Would unlock a full SCENIC-pipeline recipe on top of the new GRN-inference recipe. Surfaced 2026-05-28.
- **ADMET-AI / AdmetLab 3.0 / Deep-PK wrapper** — none of the leading ML-based ADMET predictors ([Swanson et al., *Bioinformatics* 2024](https://doi.org/10.1093/bioinformatics/btae416); [Fu et al., *NAR* 2024](https://doi.org/10.1093/nar/gkae236)) has a Claude-installable wrapper (skill, MCP server, or plugin) in [`catalog/tools/`](../catalog/) today. Their inclusion would upgrade the *Estimate PK properties* recipe from descriptor-and-analog-anchored estimation to a defensible ML-prediction layer for endpoints (CYP isoform IC50, hERG IC50, microsomal clearance) that pure descriptors miss. Surfaced 2026-05-27.
- **MARRVEL-MCP** ([bioRxiv 2025-11-26](https://www.biorxiv.org/content/10.1101/2025.11.26.690887v1), [`hyunhwan-bcm/MARRVEL_MCP`](https://github.com/hyunhwan-bcm/MARRVEL_MCP/)) — rare-disease variant-interpretation MCP server with 39 tools and a published 95%-accuracy benchmark on 45 expert-curated tasks. Would strengthen the *Interpret a clinical variant* recipe from `Proposed` to `Reported` and open a Mendelian-disease-specific recipe. Surfaced 2026-05-23.
