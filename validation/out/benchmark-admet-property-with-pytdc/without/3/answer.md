## 1. Official setup (verified against the live TDC leaderboard page)

- **Dataset:** `Caco2_Wang` (906 compounds), part of TDC's `admet_group` benchmark.
- **Split:** frozen scaffold split, generated by `admet_group`'s built-in `get_train_valid_split(..., split_type='default', seed=seed)` — this *is* the canonical split TDC uses to score leaderboard submissions, so using anything else won't be comparable.
- **Metric:** MAE, lower is better, and the protocol requires 5 seeds (1–5) averaged as mean ± std — `group.evaluate_many()` enforces this format.

## 2. Script (Morgan fingerprints + Random Forest, TDC's own submission pattern)

```python
from tdc.benchmark_group import admet_group
from rdkit import Chem
from rdkit.Chem import AllChem, DataStructs
import numpy as np
from sklearn.ensemble import RandomForestRegressor

group = admet_group(path='data/')
predictions_list = []

def smiles_to_morgan(smiles_list, radius=2, n_bits=1024):
    X = np.zeros((len(smiles_list), n_bits), dtype=np.int8)
    for i, smi in enumerate(smiles_list):
        mol = Chem.MolFromSmiles(smi)
        fp = AllChem.GetMorganFingerprintAsBitVect(mol, radius, nBits=n_bits)
        DataStructs.ConvertToNumpyArray(fp, X[i])
    return X

for seed in [1, 2, 3, 4, 5]:
    benchmark = group.get('Caco2_Wang')
    name = benchmark['name']
    train_val, test = benchmark['train_val'], benchmark['test']
    train, valid = group.get_train_valid_split(benchmark=name, split_type='default', seed=seed)

    X_train = smiles_to_morgan(train['Drug'].tolist())
    y_train = train['Y'].values
    X_test  = smiles_to_morgan(test['Drug'].tolist())

    model = RandomForestRegressor(n_estimators=500, n_jobs=-1, random_state=seed)
    model.fit(X_train, y_train)
    y_pred = model.predict(X_test)

    predictions_list.append({name: y_pred})

results = group.evaluate_many(predictions_list)
print(results)   # -> {'caco2_wang': [mean_MAE, std_MAE]}
```
