- **SciTeX Dataset MCP** (added 2026-06-28) — `scitex` PyPI package (AGPL-3.0-only, v2.30.2 released 2026-06-20, Beta), MCP server launched via the `scitex mcp start` console script. Its `scitex.dataset` module (install the `[dataset]` extra) gives Claude a unified read-only search across **OpenNeuro / DANDI / PhysioNet / Zenodo** for BIDS/NWB neuroscience datasets (per-repo fetchers + `search_datasets` text query). Catalogued at `scitex.md`, tagged Neuroscience; complements `neurosift.md` (per-file NWB inspection). Per-tool MCP names not enumerated upstream — marked `Unverified —` inline (tool list reflects the documented Python API surface). The wider SciTeX ecosystem (37 packages) bundles many non-neuroscience MCP tools; only the `dataset` module is catalogued.
- **ChatSpatial (MCP server)** (added 2026-06-27) — `cafferychen777/ChatSpatial` (MIT, v1.2.10), PyPI `chatspatial` + GHCR Docker image. The README markets it as "a curated collection of open-source medical and bioinformatics skills," but (a) there is **no LICENSE file** in the repo, and (b) **185 of 449 `SKILL.md` files carry a per-file proprietary header**: "All Rights Reserved. Generating "Free / OSS" catalog pages over a collection that is partly all-rights-reserved would be inaccurate and is not done. **Do not ingest** until upstream publishes a single coherent repo license (or per-skill licenses we can read programmatically). Note: most of OpenClaw's life-science surface (it shares many skill slugs with K-Dense/SciAgent — adaptyv, anndata, alphafold, arboreto, …) is already catalogued from the two cleanly-licensed collections, so the unique-coverage loss from deferring is small.
