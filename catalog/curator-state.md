# Curator state

## Recently surfaced

- **Drug Research / Drug Target Validation / Drug Synergy (ToolUniverse Claude Skills)** (added 2026-06-21) — three previously-deferred ToolUniverse sibling agent skills catalogued on the Drug Repurposing and Discovery directed pass, each verified against its upstream `SKILL.md`. `tooluniverse-drug-research` (`tooluniverse-drug-research.md`): 12-step comprehensive drug dossier — identifier disambiguation, chemistry/ADMET, mechanism+targets, trials, FAERS safety, pharmacogenomics, regulatory history (Drug Repurposing and Discovery, Translational Medicine). `tooluniverse-drug-target-validation` (`tooluniverse-drug-target-validation.md`): four-gate 0–100 Target Validation Score with GO/NO-GO tiers (Drug Repurposing and Discovery, Molecular and Cellular Biology, Translational Medicine). `tooluniverse-drug-synergy` (`tooluniverse-drug-synergy.md`): Bliss/HSA/Loewe/ZIP/Chou-Talalay synergy scoring over user-supplied effect data (Drug Repurposing and Discovery). All require the ToolUniverse MCP (`uvx tooluniverse`); install via `npx skills add mims-harvard/ToolUniverse` or manual clone-and-copy; all set `disable-model-invocation: true`. Apache-2.0.
- **Medical Terminologies MCP** (added 2026-06-21) — `SidneyBissoli/medical-terminologies-mcp` (MIT, npm `medical-terminologies-mcp`), a single-install MCP exposing 31 tools (37 with SNOMED enabled) across ICD-11, SNOMED CT, LOINC, RxNorm, MeSH, and ATC, with cross-terminology search/mapping, caching, and rate limiting. ICD-11 tools need free WHO ICD API credentials (`WHO_CLIENT_ID`/`WHO_CLIENT_SECRET`); SNOMED CT is reference-only without an IHTSDO license. Surfaced on the Translational Medicine directed pass (`ICD-10 SNOMED RxNorm terminology MCP server` query). Distinct from the single-terminology Anthropic `icd-10-codes` connector — catalogued at `medical-terminologies-mcp.md`, tagged Translational Medicine. Also installable via Smithery.
- **Momentum FHIR MCP Server** (added 2026-06-21) — `the-momentum/fhir-mcp-server` (MIT), a FHIR R4 MCP server with full CRUD across Patient/Observation/Condition/Medication/Immunization/Encounter/AllergyIntolerance/FamilyMemberHistory plus AI-powered document ingestion/chunking and Pinecone-backed semantic search over clinical documents, and LOINC retrieval. Source-install only (no PyPI): `git clone` + `make uv` (or `make build` for Docker), then `claude mcp add --transport stdio fhir-momentum -- uv run --frozen --directory /path/... start`. Surfaced on the Translational Medicine directed pass (`FHIR MCP server Claude install` query). Distinct from the WSO2 FHIR MCP (bare CRUD bridge) and Anthropic `fhir-developer` (authoring plugin) — Momentum adds document RAG. Catalogued at `fhir-momentum.md`, tagged Translational Medicine. Semantic-search tools require Pinecone.
- **google-deepmind/science-skills collection** (added 2026-06-20) — new first-party skill collection (`google-deepmind/science-skills`, Apache-2.0 code / CC-BY-4.0 docs, ~37 skills following the Agent Skills `SKILL.md` spec). Surfaced via `GoekeLab/awesome-genomic-skills` on the Molecular and Cellular Biology directed pass. Most skills wrap databases already catalogued (chembl, clinvar, dbsnp, ensembl, gnomad, encode, gtopdb-equivalent, interpro, jaspar, pdb, pubchem, pubmed, quickgo, reactome, string, uniprot, opentargets, openfda, human-protein-atlas, clinical-trials, literature search). Install path upstream is `npx skills add google-deepmind/science-skills/` but that writes to `~/.gemini/config/skills/` (Gemini/Antigravity); for Claude the followable path is `git clone` + `cp -r skills/<slug> ~/.claude/skills/` (plus the shared `scienceskillscommon` helper dir). Diff-only mode going forward — see Deferred for the remaining new-to-catalog skills.
- **OpenMM MCP Server** (added 2026-06-20) — `PhelanShao/openmm-mcp-server` (GPLv3), a discrete stdio MCP server that runs OpenMM molecular dynamics (basic/advanced MD, protein + membrane setup templates, metadynamics/free-energy sampling) and Abacus DFT jobs via discrete tools (`create_md_simulation`, `create_advanced_md_simulation`, `setup_protein_simulation`, `setup_membrane_simulation`, `create_dft_calculation`, `control_simulation`, `get_task_status`/`list_all_tasks`, `analyze_results`) with async task persistence. Install: clone + `pip install -r requirements.txt`, then `claude mcp add --transport stdio openmm-server -- python /path/to/openmm-mcp-server/run_openmm_server.py` (or the `cwd`-based `claude_desktop_config.json` form for Desktop). Surfaced on the Integrative Structural and Computational Biology directed pass (`OpenMM molecular dynamics MCP server` query). Distinct from the K-Dense `molecular-dynamics` *skill* (`molecular-dynamics.md`), which teaches Claude to write/run OpenMM Python directly — this is an MCP server that exposes MD/DFT as managed tool calls. Tagged Integrative Structural and Computational Biology + Drug Repurposing and Discovery. `requirements.txt` exact contents marked `Unverified —` (read from README excerpt).
