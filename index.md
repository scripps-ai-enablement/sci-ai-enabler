## Shape this resource

The catalog, guide, tracker, and recipes grow in response to user input — and the Composer can file what it learns back automatically. If something's missing or you tried a recipe and want to report back, [file an issue](https://github.com/scripps-ai-enablement/sci-ai-enabler/issues/new/choose); a bot replies in-thread within minutes and the next daily curator run ships any durable change.

[How and why →](contribute.html){: .btn }

## Stay current

Four independent curators refresh the catalog, guide, tracker, and recipes daily and post a notice to a pinned GitHub issue when content changes. [Watch the repository](https://github.com/scripps-ai-enablement/sci-ai-enabler) to subscribe. Search any page from the box at the top.
